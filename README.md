# 專案結構
- CLAUDE.md：AI 整理與開發規則。
- index.html：首頁與論文清單。
- papers/：論文筆記頁面。
- assets/style.css：共用樣式。
- templates/paper.html：文章範本。
# GitHub Pages 部署
1. 建立公開 Repository，上傳完整專案，讓 index.html 位於根目錄。
2. 進入 Settings → Pages。
3. 選擇 Deploy from a branch → main → /(root) → Save。
4. 等待部署完成，開啟 Pages 顯示的網址，檢查首頁與文章連結。
